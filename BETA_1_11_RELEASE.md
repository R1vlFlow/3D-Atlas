# 3D Anatomy Atlas — Beta 1.11

## Anatomical Laboratory

- Interactive bone-part laboratory.
- Select a bone element from the catalog.
- Focus camera on a matched mesh when available.
- Isolate the matched mesh.
- Show an in-scene anatomical label for the selected element.
- Explicitly reports when the current GLB does not contain a separate mesh for an element.
- Parent bone and element navigation remain available.

### Important
The laboratory does not fabricate 3D mappings. If an element has no confirmed mesh match, the UI says so.
