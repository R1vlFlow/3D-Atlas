# Changelog

## 0.8 Beta
- GitHub Pages-ready modular app
- Independent 3D viewer layer
- Remote separated-skeleton model candidate with fallback
- Raycast mesh selection
- Model/object name surfaced in UI
- Anatomy database kept independent from model
- Search, bones, canals, entrance/exit/contents
- Progress and quiz
- Attribution documentation

## 0.7 Beta
- First GitHub-ready modular structure

## 0.9.0-beta
- Added automatic GitHub Pages deployment workflow.
- Added `.nojekyll` compatibility file.
- Added a dedicated 3D structure-mapping issue template.
- Added a beta release checklist.

## 0.95.0-beta
- Added mesh-name normalization and anatomy-record matching.
- Clicking a 3D mesh can now open the matching anatomy card automatically.
- Added focus, isolate, and show-all controls for mapped structures.
- Added keyboard shortcuts: R = reset view, I = isolate, A = show all.
- Added local progress counter for viewed structures.

## 0.98.0-beta
- Added structure tree filters: all / paired / unpaired bones.
- Added side metadata display (L/R when encoded by structure aliases).
- Improved model-selection cards and prepared the UI for left/right navigation.
