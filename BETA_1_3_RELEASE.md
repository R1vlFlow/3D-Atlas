# 3D Anatomy Atlas — Beta 1.3

## Что изменилось
- Расширена учебная база черепа: дополнительные кости и отдельный раздел отверстий/щелей.
- Для каналов и отверстий сохранены поля «вход / выход / содержимое».
- Добавлена техническая панель Mapping 3D ↔ база: количество записей, mesh и найденных сопоставлений.
- Исправлен фильтр парных/непарных костей: используется стабильный `typeKey`.
- Добавлен локальный сброс прогресса.
- Поиск и режим «Найди» учитывают расширенную базу.

## Важно
Mapping является диагностикой по именам mesh. Для полного точного атласа потребуется отдельная ручная/полуавтоматическая карта идентификаторов конкретного 3D-ассета.
