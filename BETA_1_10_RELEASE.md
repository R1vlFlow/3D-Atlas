# 3D Anatomy Atlas — Beta 1.10

## Интерактивные элементы костей

Beta 1.10 добавляет отдельный каталог анатомических элементов костей поверх базы `bone_parts.json`.

- элементы получают собственные IDs;
- русское и латинское название сохраняются отдельно;
- элементы становятся кнопками внутри карточки кости;
- для 3D-моделей выполняется отдельный поиск mesh по латинским/русским именам;
- если отдельного mesh нет, интерфейс явно сообщает об этом вместо выдуманного положения;
- клик по подходящему mesh может открыть карточку конкретного элемента.

Версия: `1.10.0-beta`.
