3D ANATOMY ATLAS — OPEN BETA 0.6

WHAT THIS BUILD CONTAINS
- Three.js 3D viewer
- Real skull GLB technical asset
- Mouse orbit / zoom
- Clickable 3D mesh selection
- Anatomy search
- Russian + Latin names
- Educational anatomy cards
- Canals with entrance / exit / contents
- Layer toggles
- Study progress stored locally in browser
- Favorites
- Mini quiz
- Keyboard shortcuts
- Beta information panel

HOW TO RUN
1. Open 3D_Anatomy_Atlas_BETA_0_6.html in a modern browser.
2. Internet is currently required because Three.js and the GLB are loaded from public CDN/GitHub URLs.
3. For the next production-beta build, package the GLB and JS dependencies locally so the atlas can work offline.
